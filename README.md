# Grandine Alert — versione GitHub Pages

Questa cartella contiene la PWA completa e autonoma, pronta per GitHub Pages.

## Pubblicazione

1. Crea su GitHub un nuovo repository pubblico chiamato `grandine-alert`.
2. Carica **il contenuto di questa cartella**, non la cartella esterna.
3. Apri `Settings` → `Pages`.
4. In `Build and deployment`, scegli `GitHub Actions`.
5. Attendi la conclusione dell'operazione `Pubblica Grandine Alert` nella scheda `Actions`.
6. Apri l'indirizzo mostrato da GitHub Pages con Safari.
7. Premi `Condividi` → `Aggiungi alla schermata Home`.

Prima di reinstallare, elimina dalla Home la vecchia icona con la lettera G.

## Aggiornamenti successivi

Ogni modifica caricata nel ramo `main` viene pubblicata automaticamente.
