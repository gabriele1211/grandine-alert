AGGIORNAMENTO SU GITHUB
1. Estrai questo file ZIP.
2. Apri su GitHub il repository grandine-alert.
3. Premi Add file > Upload files.
4. Carica TUTTO il contenuto della cartella Grandine-Alert-0.7-BETA-GitHub
   nella radice del repository, sostituendo i file con lo stesso nome.
5. Conferma con Commit changes.
6. Lascia Settings > Pages impostato su main / (root).

CONTROLLO
Dopo la pubblicazione, chiudi completamente la PWA e riaprila. Devi vedere:
- “APP METEO LOCALE · v0.7” nell'intestazione;
- il riquadro verde “Aggiornamento completato”.

Se non compaiono, GitHub o iPhone stanno ancora mostrando i file precedenti.
