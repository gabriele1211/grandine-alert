GRANDINE ALERT — VERSIONE 0.3 BETA

MIGLIORAMENTI DEL RADAR
- Cartina sensibilmente più luminosa e leggibile.
- Fondo grigio medio neutro, senza dominante blu.
- Città, strade e confini più riconoscibili.
- Fenomeni azzurri, gialli, arancioni e rossi più brillanti.
- Fascio radar molto più largo, luminoso e sfumato.
- Cerchi delle distanze bianchi e maggiormente visibili.

AGGIORNAMENTO SU GITHUB
1. Estrai questo file ZIP.
2. Apri su GitHub il repository grandine-alert.
3. Premi Add file > Upload files.
4. Carica TUTTO il contenuto della cartella Grandine-Alert-0.3-BETA-GitHub
   nella radice del repository, sostituendo i file con lo stesso nome.
5. Conferma con Commit changes.
6. Lascia Settings > Pages impostato su main / (root).

La Versione 0.2 Beta rileverà la disponibilità della Versione 0.3 Beta quando
l'app torna in primo piano oppure durante il controllo automatico periodico.
