GRANDINE ALERT — VERSIONE 0.1 BETA

1. Apri su GitHub il repository grandine-alert.
2. Premi Add file > Upload files.
3. Carica TUTTO il contenuto di questa cartella nella radice del repository.
4. Conferma con Commit changes.
5. Lascia Settings > Pages impostato su main / (root).

Il numero «Versione 0.1 Beta» sarà visibile in fondo all'app.

Per provare l'avviso di aggiornamento, lascia aperta la vecchia Versione 0 mentre
carichi questi file. Essa controlla ogni 15 minuti. Se invece riaprendo l'app appare
già «Versione 0.1 Beta», l'aggiornamento è già avvenuto e l'avviso non serve più.

Dalla 0.1 Beta, l'app verifica nuove versioni anche quando torna in primo piano.
